# smallx

X の指定アカウントの投稿を、原文のまま読むための静的サイトです。

- 公開URL: https://tomochi3.github.io/smallx/ （GitHub Pages: `main` ブランチ / ルート）
- 更新: 自宅の MacBook で動く [tomochi3/24h](https://github.com/tomochi3/24h) の `xdigest` が毎朝 X API から取得し、自動で commit / push します。
- **このリポジトリの HTML は自動生成です。手で編集しても次回の更新で上書きされます。** 元データは `data/posts/YYYY-MM.json` です。

各投稿の著作権は投稿者にあります。
